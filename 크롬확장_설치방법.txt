■ 뮤직웨이브 팝업 알림 (크롬 확장 프로그램) 설치 방법

멜론 뮤직웨이브에 팝업창이 뜨면 핸드폰으로 알림을 보내줍니다.
윈도우와 맥 모두 사용할 수 있어요. 알림을 누르면 Chrome 원격 데스크톱이 열려요.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 확장 프로그램 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ① 압축을 풀어 "뮤직웨이브팝업알림" 폴더를 원하는 곳에 두세요
    (설치 후에도 이 폴더를 지우거나 옮기면 안 돼요)
 ② 크롬 주소창에 chrome://extensions 입력
 ③ 오른쪽 위 "개발자 모드" 켜기
 ④ 왼쪽 위 "압축해제된 확장 프로그램 로드" 클릭
 ⑤ ①의 "뮤직웨이브팝업알림" 폴더 선택 (맥은 폴더를 고르고 "선택")
 ⑥ 자동으로 설정 창이 열리고 "내 알림 방 이름"이 보여요
 ⑦ 주소창 옆 퍼즐 모양 아이콘 → 초록 음표 옆 핀(📌) 누르면
    아이콘이 항상 보여서 편해요


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 핸드폰 연결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ① 핸드폰에 "ntfy" 앱 설치 (무료)
    안드로이드: https://play.google.com/store/apps/details?id=io.heckel.ntfy
    아이폰:     https://apps.apple.com/kr/app/ntfy/id1625396347
 ② 앱에서 + 누르고 내 알림 방 이름을 똑같이 입력해 구독
    (대문자, _, 숫자까지 정확히)
 ③ 크롬의 초록 음표 아이콘 → "테스트 알림 보내기"
 ④ 핸드폰에 알림이 오면 완료!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. 사용할 때
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 - 뮤직웨이브를 열면 초록 음표 아이콘에 "ON"이 표시돼요 = 감시 중
 - 크롬 창을 최소화하거나 다른 창으로 가려도 괜찮아요
 - 모니터를 꺼도 괜찮아요
 - 크롬과 뮤직웨이브 탭은 닫으면 안 돼요
 - 컴퓨터가 잠자기(절전)에 들어가지 않게 해주세요
   윈도우: 설정 → 시스템 → 전원 및 절전 → 절전 모드 "안 함"
   맥: 시스템 설정 → 에너지(노트북은 배터리 → 옵션) →
       "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지" 켜기
       맥북은 덮개를 닫으면 잠자기에 들어가니 열어두세요


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. 알아두세요
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 - 크롬을 켤 때 "개발자 모드 확장 프로그램을 사용 중지하세요"
   안내가 뜰 수 있어요. 이건 닫기(X)만 누르면 되고, 사용 중지를
   누르면 안 돼요
 - 알림 방 이름은 다른 사람과 공유하지 마세요 (알림이 섞여요)
 - 팝업을 자동으로 꺼주는 건 아니고 알림만 보내줘요
 - "알림 수신 중" 표시가 거슬리면 (안드로이드):
   ntfy 앱 → 구독한 방 → 오른쪽 위 메뉴 → 설정 → "즉시 전송" 끄기
